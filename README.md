**AVISO:** las páginas son **borradores para revisión**, no versiones contractuales definitivas. Contienen verificaciones jurídicas y técnicas pendientes. No deben utilizarse como aceptación de Términos en producción.

El workflow `.github/workflows/pages.yml` genera el sitio desde `TERMINOS.md` y `PRIVACIDAD.md`, sin copias manuales; se publica automáticamente después de cada cambio a esos archivos en `main`.

En una Activity local se pueden configurar `VITE_TERMS_URL` y `VITE_PRIVACY_URL` a las rutas anteriores **solo para revisar el diseño y probar la integración antes del lanzamiento**. Para producción habrá que finalizar la revisión, retirar los marcadores pendientes y aprobar expresamente una nueva versión de los Términos.
